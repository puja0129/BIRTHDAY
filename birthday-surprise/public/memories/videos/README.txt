Place your videos here.

Naming suggestion:
  video1.mp4, video2.mp4, etc.

Then update the videos in:
  src/data/content.js → VIDEOS array

Example:
  src: "/memories/videos/video1.mp4"
  thumbnail: "/memories/videos/thumb1.jpg"

Recommended: compress videos before uploading to Vercel.
Vercel free plan has a 100MB file size limit per file.
